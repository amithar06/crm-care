CRM Care - Customer Data Quality & Support Operations

A self-contained interactive portfolio prototype built with HTML, CSS and JavaScript.

How to open:
1. Open index.html in Chrome, Edge, Firefox or Safari.
2. No installation, server, account, or internet connection is required after the file is downloaded.
3. Use the left navigation to explore Overview, Data Quality, Support Queue and Workflow Monitor.

Try these interactions:
- Data quality: mark a record reviewed, filter by issue type, and export CSV.
- Support queue: log a new fictional issue and change a ticket status.
- Workflow monitor: simulate a failed workflow run and retry sample runs.
- Overview: export a summary CSV.

Important:
- All people, companies, records, support incidents, and workflow runs are fictional.
- This prototype does not connect to RecruitCRM, Zapier, Workato, or any real customer system.
- It demonstrates a proposed process and should not be described as a deployed production system.
